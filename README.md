# Hi, I’m James Chidubem Praise 👋

**You can call me Probix.** I'm a Nigerian software developer and student at Michael Okpara University of Agriculture, Umudike (MOUAU). I build web and desktop applications, explore AI-powered tools, and enjoy bringing practical ideas to life.

I'm especially interested in useful technology for learning, communication, and creative work—including tools that make digital experiences more accessible to African-language speakers.

## 🚀 What I'm working on

- 🧠 **Probix AI** — exploring multilingual learning and practical AI-assisted tools.
- 🖥️ **[GEN3D Studio Live](https://github.com/praisecyber/GEN3D-STUDIO-LIVE)** — an Electron and React desktop workspace for presentation and live production.
- 🚕 **[Campus Autonomous Taxi](https://github.com/praisecyber/Autonomous-Taxi)** — a collaborative project exploring a React interface and connected hardware with ESP32-CAM and Arduino.
- 🎙️ **Yoruba text-to-speech** — learning about speech datasets, Python, PyTorch, and StyleTTS2.
